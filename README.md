# Real-Estate-Website
A full-stack real estate web application designed to display and manage property listings through a modern web interface.

Overview

This project combines a React frontend with a .NET backend API and database integration. The application allows users to interact with property listings through a web-based interface.

Features:

Display property listings
React-based user interface
REST API integration
Property listing data management
Database connectivity
Responsive web design
Frontend-to-backend communication
API testing with Swagger

Architecture

The application follows a basic full-stack architecture:

React Frontend
       ↓
ASP.NET Core Web API
       ↓
SQL Server Database

The React frontend communicates with the .NET API to retrieve and work with property listing data.

API

The backend provides API endpoints for interacting with property listings.

Swagger is used during development to test and document the API endpoints.

How to Run:

Frontend
Clone the repository.
Open the frontend project in VS Code.
Install dependencies:
npm install
Start the development server:
npm run dev
Backend
Open the backend project in Visual Studio.
Restore the .NET dependencies.
Configure the SQL Server connection.
Start the ASP.NET Core API.
Use Swagger to verify the API is running.
